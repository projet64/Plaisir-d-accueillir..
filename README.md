# Plaisir d'accueillir — prototype v0.1

Prototype responsive PC / iPad / iPhone.

Fonctions déjà présentes :
- accueil visuel
- recherche recettes / ingrédients / occasions
- filtres par catégorie
- fiches recettes
- recalcul des quantités selon le nombre de convives
- ajout à la liste de courses
- liste de courses avec cases à cocher
- souvenirs / invités / occasions
- stockage local dans le navigateur
- manifest PWA + service worker prêts pour hébergement

Pour tester immédiatement : ouvrir index.html dans un navigateur.
Pour profiter de l'installation PWA sur iPhone/iPad/PC, héberger le dossier sur un serveur HTTPS.
